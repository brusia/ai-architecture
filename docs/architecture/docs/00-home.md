# Migration Copilot

Агентный **copilot для миграции ML-моделей** на целевой вычислитель. Инженер работает с ним из терминала: агент читает протокол миграции из библиотеки `migration`, анализирует и правит код в репозитории модели, вызывает LLM и продвигается по фазам, останавливаясь на контрольных точках **GATE** для подтверждения инженером.

Архитектура описана в двух вариантах — **MVP** и **Production**, — которые используют общий набор внешних систем и артефактов (раздел **Common**).

## Варианты

### MVP (Qwen Code)
Агентный CLI-copilot, работающий полностью локально у инженера. Контекст собирается прямым чтением файлов протокола и репозитория — без векторного поиска и без накопления опыта между миграциями. Ядро — `Qwen Code CLI` и локальная LLM.

### Production (Hermes)
Гибридный агент из локального и центрального шлюзов. В отличие от MVP, **накапливает опыт** (skills и memory) между миграциями и делится им в команде через центральный шлюз, работает на self-hosted LLM с резервированием и полной наблюдаемостью.

## Common — общее для обоих вариантов

| Блок | Роль |
|---|---|
| **GitLab CI + ClearML** | Сборка и проверка: конвертация модели (ONNX→TensorRT), кросс-платформенные тесты, трекинг экспериментов |
| **pypi-local / artifact storage** | Хранилище дистрибутива `migration` и целевых артефактов модели (`.onnx`, `.engine`) |
| **Observability + Alerting** | Метрики, дашборды, логи, трейсы и алертинг по всей платформе |
| **IdP + Vault** | SSO (OIDC), секреты и ролевой доступ |
| **Репозиторий модели** | Рабочая копия портируемой модели; каждая миграция — в ветке `migrate-<model>` |
| **Библиотека migration** | Носитель неизменного процесса: навигатор, пофазные инструкции, контракты |

## Навигация по диаграммам

Диаграммы уровней C1–C4 для каждого варианта доступны через меню слева (**Migration Copilot — MVP** и **Migration Copilot — Production**).
