
# Постановка

## Необходимые шаги

### Анализ требований

На основе легенды сформулировать 5-7 уточняющих вопросов клиенту для снятия неопределенности.

### Выбор контракта

Обосновать выбор модели (T&M, FP или гибрид) для этапа PoC и для основной разработки. Поясните, почему это выгодно обеим сторонам.

### Оценка рисков

Составить матрицу рисков (минимум 5 рисков), специфичных для AI (например, качество данных, галлюцинации модели). Предложите план митигации.

### Roadmap

Разработать дорожную карту. Опишите критерии успеха (DoD) для этапов:

- PoC (проверка гипотезы)
- MVP (выход на пользователей)
- Production (масштабирование)

## Формат сдачи

PDF-файл (или ссылка на Google Doc/Holst) содержащий:

Список вопросов.
Обоснование контракта.
Матрицу рисков.
Схему/Таблицу Roadmap.

## Критерии оценки

### Обоснованность

Выбор типа контракта логично вытекает из уровня неопределенности.

### Полнота

Roadmap покрывает все три стадии (PoC, MVP, Prod).

### Реалистичность

Риски специфичны для AI-проектов, а не общие фразы.

### Структура

Документ читаем и понятен для бизнеса
