# Описание проекта

Данный репозиторий будет использоваться в ходе изучения курса AI-архитектор (OTUS).

В рамках выполнения итоговой проектной работы предлагается выполнить ряд домашних заданий, вся совокупность которых приведёт к полноценной реализации и защите итоговой проектной работы.

## Цель проектной работы

### Разработка агентной системы для интеграции внутренних DevTools инструментов в репозитории DS команд

Наша команда занимаемся оптимизацией и портированием нейросетевых решений на целевые устройства (Edge AI) в рамках продуктов компании, в том числе привнося новый уровень MLOps зрелости, обеспечивая сквозную интеграцию нейросетевых моделей из среды разработки в среду эксплуатации.

Командой разработана внутренняя библиотека, позволяющая обобщить миграцию обучаемых нейросетевых моделей (из фреймворков, используемых при обучении) под разные целевые платформы.

Для интеграции этого решения в репозитории DS-команд предполагается разработка агентной системы, которая будет анализировать существующую кодовую базу и существующие непортируемые операции, предлагать DS-инженеру варианты оптимизации и/или разделения модели на части (при невозможность переписать непортируемые слои), получать от него указания и интегрировать разработанное решение в репозиторий, в котором ведётся работа. После реализации инженер получает набор артефактов, совместимых с требуемой платформой.

Агент/агентная система также реализует интеграцию библиотеки для оценки просадки портированной модели с исходной и предоставляет автоматизированный скрипт о принятии решения, корректно ли выполнена оптимизация на предыдущем шаге. Данная оценка осуществляется на основании метрик, используемых DS-командой.

При возникновении затруднений и/или неоднозначностей агент задаёт уточняющие вопросы DS-инженеру, осуществляющему интеграцию.

По результатам работы репозиторий DS-команды содержит реализованные скрипты для 
**1.** Получения оптимизированных, платформ-специфичных артефактов (нейросетевых моделей, бинарники)
**2.** Оценки точности и сравнения полученных результатов для целевых моделей с исходными
**3 (опционально).** Настроенный ci-процесс, запускаемый автоматически при получении нового чекпоинта для разработываемой модели, обновлении архитектуры модели, изменениях в датасете и/или ручному триггеру. Результатом этого полностью отслеживаемого и воспроизводимого процесса является набор артфактов, специфичных для каждой из целевых платформ.

### Потребитель решения

DS-инженер либо инженер оптимизации (вместо ручной интеграции он использует агента, автоматизирующего большую часть работы).
